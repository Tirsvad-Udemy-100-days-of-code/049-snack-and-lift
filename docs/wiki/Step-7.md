# Step 7: Verify on the My Bookings page

## What you gain

You learn to check your own work from a second source: `get_my_bookings()` reads the My Bookings page (bookings and waitlist entries) and `verify_bookings()` compares it with what the bot did. The result is SUCCESS or MISMATCH (exit code 3).

## Where it is in the code

`src/snack_and_lift/application/verification.py`
