# Step 3: Book the next Tuesday class

## What you gain

You learn to find an element relative to another one: the day group of the next Tuesday is found with an XPath ancestor lookup, then the 6pm card and its button. `book_class()` clicks the button and waits until its text changes.

## Where it is in the code

`src/snack_and_lift/application/booking.py`
