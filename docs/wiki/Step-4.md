# Step 4: Check if a class is already booked

## What you gain

You learn to read the state of a button before acting: "Book Class", "Join Waitlist", "Booked" or "Waitlisted". A class that is already booked is not clicked again, and the bot prints a ✓ line that says what it did.

## Where it is in the code
